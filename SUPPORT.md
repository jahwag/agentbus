# Support

Join [The Orchard Discord](https://discord.gg/pR4qeMH4u4) for community help
and discussion. Use GitHub Issues for reproducible defects and focused feature
proposals. Include the AgentBus version, operating system, deployment topology,
relevant sanitized logs, and exact reproduction steps.

Security reports belong in a private GitHub Security Advisory or a direct
message to `@jahwag` in The Orchard, as described in `SECURITY.md`. Never post
vulnerabilities, credentials, databases, or raw mailbox payloads in a public
Discord channel or issue.

Deployment design, incident response, data recovery, and operational consulting
are outside community support. Contact the maintainer privately if professional
support is required.
